# Automobile Price Prediction App

A Streamlit app that lets people enter vehicle specifications and receive a price estimate from a trained Random Forest or Linear Regression pipeline.

## Project structure

```text
automobile_price_prediction_app/
├── Automobile_data.csv
├── train_model.py
├── app.py
├── requirements.txt
└── artifacts/
    ├── random_forest_pipeline.pkl
    ├── linear_regression_pipeline.pkl
    ├── app_metadata.json
    ├── metrics.json
    └── actual_vs_predicted.png
```

The `artifacts/` files are generated by the training script; they are not included in this starter ZIP because your dataset is not included.

## Run locally

1. Install Python 3.10 or newer.
2. Put your `Automobile_data.csv` in this project folder.
3. Open a terminal in this folder and install dependencies:

   ```bash
   python -m pip install -r requirements.txt
   ```

4. Train models and generate the saved pipelines:

   ```bash
   python train_model.py
   ```

5. Start the app:

   ```bash
   streamlit run app.py
   ```

Streamlit prints a local URL, usually `http://localhost:8501`.

## Deploy publicly with Streamlit Community Cloud

1. Create a GitHub repository and upload `app.py`, `train_model.py`, `requirements.txt`, and the generated `artifacts/` files.
2. Ensure the model artifact files are in the `artifacts` folder in the repository.
3. Open https://share.streamlit.io/ and connect GitHub.
4. Create an app using your repository and set the main file to `app.py`.
5. Deploy. Share the public app URL.

The CSV is only required for training. The deployed app uses the saved model pipelines and metadata, so it does not need to retrain on every visit.

## Important notes

- Only load `.pkl` files that you created or trust. Joblib/pickle files can execute code when loaded.
- The prediction amount uses the units/currency represented by the dataset's `price` column.
- Keep model files and `scikit-learn` versions compatible between training and deployment.
- If the dataset is licensed or contains private data, check that you are allowed to publish it and the generated artifacts.
- The model is an estimate and may be inaccurate for cars unlike those in the training data.
